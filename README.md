# No-Code & Low-Code Community Manager Discord Bot

Automated moderation, welcome flows, role management, and engagement analytics for No-Code & Low-Code communities. Purpose-built for No-Code & Low-Code community needs.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
